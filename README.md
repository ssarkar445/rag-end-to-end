# Production RAG / AI Engineering Code

This repository contains code examples and implementations created for learning and experimentation with **RAG, LangChain, LangGraph, and production AI engineering concepts**.

> **Attribution:** The code in this repository is based on and/or adapted from the following learning resources. Full credit goes to the original creators and repositories.

[production-course-main-code](https://github.com/pdichone/production-course-main-code?utm_source=chatgpt.com)

This repository contains examples covering topics such as LangChain, LangGraph, RAG pipelines, agents, embeddings, vector stores, monitoring, and production AI patterns.

Advanced RAG examples were also referenced from:
